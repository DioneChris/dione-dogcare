# Dione 브랜드 패턴

로고의 포인터 실루엣, 브랜드 컬러, 1층 로비의 아치를 재료로 만든 패턴 3종과 적용 시안입니다.
모든 타일은 이음새 없이 반복되는 벡터(SVG)입니다.

## 컬러

| 이름 | HEX | 용도 |
| --- | --- | --- |
| Olive | `#4a502e` | 메인. 로고, 랩핑 바탕 |
| Deep Olive | `#2a2e18` | 프리미엄 바탕 (사이트의 `#222512`~`#2d311a` 계열) |
| Olive Light | `#71794c` | 톤온톤 패턴의 선 |
| 패턴 모티프 톤 | `#6b7247` | 올리브 바탕 위 톤온톤 모티프 |
| Olive Pale | `#a8b084` | 크림 바탕 위 연한 패턴 |
| Cream | `#f7f3ec` | 밝은 바탕, 올리브 위 로고 |
| Gold | `#b8975a` | 씰, 박 인쇄, 얇은 라인에만 |

## 파일

- `svg/ogee-*.svg` — 패턴 A 오지 격자 (240×344 타일). olive / deep-gold / cream
- `svg/arcade-*.svg` — 패턴 B 아케이드. allover(360×528), band(360×264, 가로 반복)
- `svg/petit-*.svg` — 패턴 C 쁘띠 (132×132 타일)
- `svg/seal-gold.svg` — 타원 씰
- `svg/vehicle-*.svg`, `svg/package.svg`, `svg/hero.svg` — 적용 시안 (벡터)
- `png/` — 위 파일의 미리보기
- `src/` — 생성 스크립트. 색이나 비율을 바꿔 다시 뽑을 때: `cd src && python3 export.py && python3 mock.py` (fonttools 필요)

차량 시안은 특정 차종이 아닌 일반 밴 실루엣입니다. 실제 랩핑은 시공 업체의 차종별 도면에 타일을 다시 얹어야 합니다.

첨부한 패턴 이미지와 로고를 그대로 사용해서 실사 목업을 만들어줘. 패턴과 로고의 형태는 바꾸지 말 것.
